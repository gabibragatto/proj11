#  Exercícios de Vetores em JavaScript

---

#  Sobre

Este projeto contém exercícios básicos de vetores em JavaScript, utilizando:

- Arrays
- Estruturas de repetição
- Condicionais
- Média de valores
- Interseção entre vetores

---

#  Exercícios

## 1️. Nomes em ordem inversa

O programa lê 7 nomes e exibe todos na ordem inversa da digitada.

###  Conceitos utilizados

- Vetores
- Laço `for`
- Percorrer vetor ao contrário

---

## 2️. Média e números acima da média

O programa lê 8 números reais, calcula a média e mostra apenas os valores acima dela.

###  Conceitos utilizados

- Soma de valores
- Média aritmética
- Condicional `if`

---

## 3️. Pessoas menores de idade

O programa lê o nome e a idade de 9 pessoas e exibe apenas os dados das pessoas menores de idade.

###  Conceitos utilizados

- Vetores relacionados
- Condicionais
- Comparação de valores

---

## 4️. Interseção entre vetores

O programa lê dois vetores com 5 números inteiros e cria um terceiro vetor contendo apenas os elementos que aparecem nos dois vetores, sem repetição.

###  Conceitos utilizados

- Comparação entre vetores
- Evitar valores repetidos

---

#  Tecnologias utilizadas

- JavaScript
- HTML
- Console do navegador
